# Nguồn lịch sử

- `references/`: PDF, DOCX nguồn và UML trước chỉnh sửa.
- `planning/`: kế hoạch 20 bước Markdown/DOCX từ mốc TypeScript cũ.

Giữ để truy vết nghiệp vụ, không dùng để quyết định stack backend. Không sửa hoặc sao chép nguyên văn PDF vào báo cáo. Nguồn đang dùng ở [mục lục tài liệu](../README.md). Manifest đã cập nhật đường dẫn; hash binary không đổi.
