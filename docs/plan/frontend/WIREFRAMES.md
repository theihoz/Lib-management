# Wireframe và ánh xạ màn hình

[Board desktop/mobile](wireframes.html) chứa 12 màn hình; dữ liệu là nhãn minh họa, chưa là frontend. Thiết kế thấp độ chi tiết để chốt thông tin và vị trí, áp dụng [direction](DESIGN-DIRECTION.md) và [motion](MOTION.md) khi code.

| ID | Màn hình | Module |
| --- | --- | --- |
| WF01 | Catalog | FE02 |
| WF02 | Quầy mượn | FE04 |
| WF03 | Quầy trả | FE05 |
| WF04 | Duyệt phí và thu | FE07 |
| WF05 | Portal độc giả | FE08 |
| WF06 | Độc giả và thẻ | FE03 |
| WF07 | Giữ chỗ và gia hạn | FE06 |
| WF08 | Báo cáo và CSV | FE09 |
| WF09 | Quy định | FE09 |
| WF10 | Tài khoản và quyền | FE10 |
| WF11 | Nhập và thanh lý | FE10 |
| WF12 | Vận hành | FE11 |

Các trạng thái ghi trên board và module: loading/empty/error/pending/success/conflict. Desktop nhân viên ưu tiên scanner/bảng; mobile ưu tiên nội dung chính, không bảng kéo ngang toàn trang. Wireframe mô tả bố cục, chưa chứng minh contrast/motion/accessibility runtime.
